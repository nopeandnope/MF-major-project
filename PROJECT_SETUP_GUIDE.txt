QUICK START - ONE COMMAND SETUP (RECOMMENDED)
============================================================

FASTEST WAY TO GET STARTED:
---------------------------
1. Create virtual environment:
   python -m venv venv

2. Activate virtual environment:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

3. Run automated setup:
   python setup_and_train_complete.py

That's it! This single command will:
✅ Install all dependencies automatically
✅ Collect 20-year historical data (200 funds)
✅ Train Gemma-2B model with LoRA fine-tuning
✅ Prepare everything for deployment

Estimated Time: 2-5 hours (depending on hardware & network)

QUICK SETUP OPTIONS:
-------------------
Skip data collection (use existing data):
  python setup_and_train_complete.py --skip-data

Skip model training (use existing model):
  python setup_and_train_complete.py --skip-training

Quick setup (skip both, just install dependencies):
  python setup_and_train_complete.py --quick

  python setup_and_train_complete.py --max-funds 100

============================================================
TROUBLESHOOTING
============================================================

PROBLEM: Import errors (ModuleNotFoundError)
SOLUTION:
  python -m pip install -r requirements.txt
  python -m pip install yfinance loguru transformers peft

PROBLEM: Hugging Face authentication error
SOLUTION:
  1. Visit https://huggingface.co/google/gemma-2b
  2. Request access and accept terms
  3. Generate token at https://huggingface.co/settings/tokens
  4. Create .env file with: HUGGINGFACE_HUB_TOKEN=your_token_here

PROBLEM: Training out of memory
SOLUTION:
  Edit train_enhanced_model.py:
  - Line 37: Change batch_size to 1
  - Line 38: Increase gradient_accumulation_steps to 32

PROBLEM: Data collection fails
SOLUTION:
  - Check internet connection
  - Reduce max_funds parameter
  - Use: python setup_and_train_complete.py --max-funds 50

PROBLEM: Port 8000 already in use
SOLUTION:
  Edit run_server.py and change port to 8001 or kill process:
  Windows: netstat -ano | findstr :8000
  Linux/Mac: lsof -ti:8000 | xargs kill

PROBLEM: Training too slow
SOLUTION:
  Quick training mode - edit train_enhanced_model.py:
  - Line 437: Change 25000 to 5000 (training examples)
  - Line 40: Change num_epochs to 2

============================================================
PERFORMANCE OPTIMIZATION
============================================================

FOR FASTER SETUP:
- Use --quick flag to skip data collection and training
- Use --max-funds 50 for minimal data collection
- Reduce training examples in train_enhanced_model.py

FOR BETTER ACCURACY:
- Collect more data: --max-funds 500
- Train longer: Increase num_epochs to 6-8
- More training examples: Change 25000 to 50000
- Use GPU if available (automatic detection)

FOR PRODUCTION:
- Set up PostgreSQL/MySQL instead of SQLite
- Use Gunicorn/uWSGI for serving
- Set up nginx reverse proxy
- Enable SSL/TLS certificates
- Implement authentication and rate limiting
- Set up monitoring (Prometheus + Grafana)

Production command:
gunicorn -w 4 -k uvicorn.workers.UvicornWorker api.app:app --bind 0.0.0.0:8000
