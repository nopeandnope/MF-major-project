================================================================================
                      1. PROJECT OVERVIEW
================================================================================

This project implements a complete AI-powered mutual fund advisor that:
- Collects 20 years of historical NAV data from 200+ Indian mutual funds
- Stores data in SQLite database with comprehensive performance metrics
- Trains Google Gemma-2B model with 25,000 investment scenarios
- Provides personalized investment recommendations via web API
- Generates 3 risk-based strategies: Low, Moderate, High
- Includes tax optimization, SIP planning, and diversification
- Offers backtesting framework for strategy validation

================================================================================
                  4. DETAILED STEP-BY-STEP GUIDE (Manual)
================================================================================

STEP 1: ENVIRONMENT SETUP (5 minutes)
──────────────────────────────────────
1. Create virtual environment:
   python -m venv venv

2. Activate virtual environment:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Create .env file with Hugging Face token:
   HUGGINGFACE_HUB_TOKEN=your_token_here

   Get token from: https://huggingface.co/settings/tokens


STEP 2: DATA COLLECTION (15-45 minutes)
────────────────────────────────────────
COMMAND:
python -c "import asyncio; from src.enhanced_20_year_collector import Enhanced20YearCollector; collector = Enhanced20YearCollector(); asyncio.run(collector.collect_20_year_data(max_funds=200))"

WHAT HAPPENS:
- Connects to MFAPI.in
- Downloads 200+ mutual funds
- Collects 20 years NAV history
- Calculates performance metrics
- Creates data/historical_20y.db

OUTPUT:
- data/historical_20y.db (50-100 MB)
- 3.6M+ NAV records
- 200+ funds with metrics

VERIFY SUCCESS:
- Check file exists: data/historical_20y.db
- Check logs for "Successfully collected data for X funds"


STEP 3: DATA VALIDATION (Optional - 2 minutes)
───────────────────────────────────────────────
COMMAND:
python -c "from src.data_quality_validator import DataQualityValidator; v = DataQualityValidator(); report = v.validate_database('data/historical_20y.db'); print(f'Quality Score: {report[\"avg_quality_score\"]}/100')"

CHECKS:
- Data completeness
- Missing values
- Outliers
- Consistency

OUTPUT:
- reports/data_quality_report.json


STEP 4: GENERATE TRAINING DATA (5-10 minutes)
──────────────────────────────────────────────
COMMAND:
python -c "from src.generate_gemma_training_data import generate_training_data; generate_training_data(num_examples=25000, output_path='data/gemma_training_data_20y.jsonl', db_path='data/historical_20y.db')"

CREATES:
- 25,000 investment scenarios
- User profiles with varying risk/goals
- Portfolio recommendations

OUTPUT:
- data/gemma_training_data_20y.jsonl (50-100 MB)


STEP 5: MODEL TRAINING (1-4 hours)
───────────────────────────────────
FOR PRODUCTION (Best Quality):
   COMMAND: python train_enhanced_model.py
   TIME: 1-4 hours (CPU), 30-60 min (GPU)
   MODEL: Gemma-2B
   OUTPUT: models/enhanced_20y_advisor/

FOR QUICK TESTING (Fast):
   COMMAND: python quick_train.py
   TIME: 5-10 minutes
   MODEL: TinyLlama-1.1B
   OUTPUT: models/quick_advisor/

WHAT HAPPENS:
- Loads base model from Hugging Face
- Applies LoRA fine-tuning
- Trains on 25K examples, 4 epochs
- Saves fine-tuned model

MEMORY REQUIREMENTS:
- Production: 8-12 GB RAM
- Quick: 4-6 GB RAM

VERIFY SUCCESS:
- Check directory exists: models/enhanced_20y_advisor/
- Check for files: pytorch_model.bin, config.json
- Check logs: "Training completed successfully"


STEP 6: TEST INFERENCE (2 minutes)
───────────────────────────────────
COMMAND:

SHOULD OUTPUT:
- 3 strategies (Low, Moderate, High risk)
- Fund recommendations for each

- Check model directory exists
- Check database exists
- Check dependencies installed

- Port: 8000

================================================================================
                     7. TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: "ModuleNotFoundError: No module named 'X'"
──────────────────────────────────────────────────
SOLUTION:
pip install X
OR
pip install -r requirements.txt

COMMON MISSING MODULES:
- IPython: pip install ipython
- bt: pip install bt
- quantstats: pip install quantstats


PROBLEM: "Database not found: data/historical_20y.db"
──────────────────────────────────────────────────────
SOLUTION:
Run data collection first:
python -c "import asyncio; from src.enhanced_20_year_collector import Enhanced20YearCollector; collector = Enhanced20YearCollector(); asyncio.run(collector.collect_20_year_data(max_funds=200))"


PROBLEM: "No such table: nav_data" or "No such table: nav_history_20y"
───────────────────────────────────────────────────────────────────────
CAUSE: Database exists but is empty or corrupted
SOLUTION:
1. Delete existing database: del data\historical_20y.db
2. Re-run data collection (see above)


PROBLEM: "CUDA out of memory" during training
──────────────────────────────────────────────
SOLUTIONS:
Option 1: Use CPU instead (slower but works)
   - Training scripts auto-fallback to CPU

Option 2: Use quick training (smaller model)
   python quick_train.py

Option 3: Reduce batch size (edit train_enhanced_model.py)
   - Change per_device_train_batch_size from 2 to 1


PROBLEM: "Token is invalid" or "401 Unauthorized" from Hugging Face
────────────────────────────────────────────────────────────────────
SOLUTION:
1. Get new token: https://huggingface.co/settings/tokens
2. Update .env file:
   HUGGINGFACE_HUB_TOKEN=your_new_token_here
3. Accept Gemma-2B license: https://huggingface.co/google/gemma-2b


PROBLEM: Training is very slow on CPU
──────────────────────────────────────
EXPECTED:
- Full training: 1-4 hours on CPU is normal
- GPU would be 30-60 minutes

SOLUTIONS:
Option 1: Use quick training
   python quick_train.py (5-10 minutes)

Option 2: Reduce training data
   Edit train_enhanced_model.py, change num_examples to 1000


PROBLEM: "Address already in use" when starting server
───────────────────────────────────────────────────────
CAUSE: Port 8000 is already in use
SOLUTION:
Option 1: Kill existing process on port 8000
   Windows: netstat -ano | findstr :8000
            taskkill /PID <PID> /F
   Linux: kill $(lsof -t -i:8000)

Option 2: Change port in run_server.py
   Edit: uvicorn.run(app, host="0.0.0.0", port=8001)


PROBLEM: API returns empty or incorrect recommendations
────────────────────────────────────────────────────────
CHECKS:
1. Model exists: models/enhanced_20y_advisor/
2. Database exists: data/historical_20y.db
3. Check logs in logs/ directory
4. Test inference directly:
   python -c "from src.inference_stable import generate_recommendations; print(generate_recommendations({'age': 30, 'income': 100000, 'goal': 'wealth', 'risk': 'moderate', 'horizon': 5}))"


PROBLEM: Backtesting fails with "insufficient data"
────────────────────────────────────────────────────
CAUSE: Not enough historical data for long timeframes (e.g., 10-year backtest)
SOLUTION: Use shorter timeframes or collect more historical data
